# 叉车人员入侵检测系统 - 设备端项目介绍

## 项目概述

本项目是一款基于边缘 AI 视觉的叉车人员入侵检测系统，部署于 MaixCAM Pro 边缘计算设备，采用 YOLO11n 轻量化模型实现实时人员检测与智能报警。系统通过双 ROI（感兴趣区域）设计与双状态机去抖算法，有效降低误报率，并通过 UART 串口与 ESP32 控制器联动，实现声光报警与云端数据上报。

## 系统架构

```
MaixCAM Pro (YOLO11 推理) → UART 串口 → ESP32 控制器 → GPIO → LED/蜂鸣器
                              ↓
                         云端上报 (HTTP/MQTT)
```

## 核心技术特性

### 1. 高性能边缘 AI 推理
- 基于 MaixPy v4.12 框架，运行于 MaixCAM Pro 硬件平台
- 采用 YOLO11n 轻量化模型，输入分辨率 832×832
- 使用双缓冲区技术 (`dual_buff=True`) 提升推理性能
- 仅检测 person 类别，专注人员入侵场景

### 2. 双 ROI 智能检测
- **中心 ROI（驾驶员区）**：覆盖画面中心 50%×50% 区域，监测驾驶员位置
- **外围 ROI（危险区）**：覆盖全画面，监测周边人员入侵
- 双区域独立检测，协同判断报警条件

### 3. 双状态机去抖算法
- 中心 ROI：连续 5 帧检测到人员 → ON，连续 10 帧未检测 → OFF
- 外围 ROI：连续 5 帧检测到人员 → ON，连续 8 帧未检测 → OFF
- 报警触发条件：中心与外围同时处于 ON 状态
- 有效过滤瞬时干扰，降低误报率

### 4. 可靠的 UART 通信协议
- 数据包格式：`<DATA,CHECKSUM>`，带校验和验证
- 预缓存常用指令包，提升通信效率
- 事件触发机制，仅在状态切换时发送数据
- 心跳包机制（1.5 秒间隔），ESP32 端 5 秒超时触发通信故障保护

### 5. 云端上报能力
- 每台设备独立标识：如`FORK-006`
- HTTP 图片上传：支持单张/批量上传报警快照
- MQTT 报警发布：`factory/forklift/{device_id}/alarm`
- 报警快照环形缓冲：1 FPS 采样，保留 60 帧，触发时回溯 3 帧
- 失败补传机制：内存队列（最多 20 条），重试间隔 5 秒，最多重试 5 次

### 6. 完善的事件日志系统
- 事件日志：记录状态切换、初始化失败、UART 错误、运行异常
- 汇总日志与 CSV 摘要：便于后期分析与追溯
- 调试模式可配置，生产环境关闭调试输出以降低性能损耗

## 关键性能指标

| 指标 | 参数 |
|------|------|
| 模型输入分辨率 | 832×832 |
| 置信度阈值 | 0.5 |
| IOU 阈值 | 0.45 |
| 心跳包间隔 | 1.5 秒 |
| UART 波特率 | 115200 |
| 报警快照采样率 | 1 FPS |
| 环形缓冲容量 | 60 帧 |

## 部署与运行

- 硬件平台：MaixCAM Pro + ESP32 控制器
- 软件框架：MaixPy v4.12 (https://github.com/sipeed/MaixPy)
- 模型训练：使用 `yolo` conda 环境，基于 ultralytics 框架
- 部署方式：将 `src/` 目录上传至 MaixCAM Pro，运行 `main.py` 即可启动

## 安全设计

- WiFi 和 MQTT 凭证独立配置，不包含在代码GitHub仓库中
- 通信故障保护：心跳超时自动触发报警，确保安全冗余
