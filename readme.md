# YSU2026大创项目-基于YOLO的叉车作业人车互斥报警系统设计与实现

本项目基于 MaixCAM Pro 与 YOLO11n 模型，实现对实时画面中 person（人） 的稳定检测，并通过 UART 串口 向 ESP32 输出状态信号，用于驱动外部设备（LED、蜂鸣器）。

---

### 功能简介

- 实时检测摄像头画面中的 **person** 类目标
- 通过 **状态机逻辑** 判断检测结果的稳定性
- 连续 N 帧检测到人时，发送 `'1'` 给 ESP32
- 连续 M 帧未检测到人时，发送 `'0'` 给 ESP32
- 仅在 **状态发生切换** 时通过 UART 发送数据，避免冗余通信

- 系统面向 **嵌入式边缘 AI** 长期运行场景

---

### 工作原理

1. 图像采集

    MaixCAM Pro 持续采集摄像头画面

2. 目标感知

    使用 YOLO11n 模型对画面进行推理，仅关注 person 类目标

3. 状态机决策

    检测结果不会直接触发外设控制，而是进入状态机进行连续帧判断，以抑制抖动与误检

4. 对外行为输出

    当系统状态发生切换时，通过 UART 向 ESP32 发送 '1' 或 '0'

5. 外设控制

    ESP32 根据接收到的状态信号执行后续控制（LED、蜂鸣器）

检测结果不会被直接用于控制，而是先经过状态机决策，以保证输出信号的稳定性与可预测性。

---

### 串口通信设计说明

- UART 通信采用 事件触发机制

- 仅在系统状态切换时发送数据

- 避免逐帧或周期性发送，降低通信负载

- 输出信号语义清晰：

    - '1'：人员存在

    - '0'：人员不存在

该设计适合长期运行场景，有利于系统稳定性与外设可靠控制。

---


### 日志与调试设计

- 系统日志仅记录状态切换与异常事件，用于长期运行后的行为复盘

- 不记录逐帧检测日志，以避免性能损耗与日志噪音

- 调试信息与系统事件日志相互独立，调试输出不会影响正式运行行为

```text
└── main.py        # 程序入口 (模块整合、主循环、UI 显示)
```
